# PowerPoint Build-Script Template

Reference architecture for generating decks. Every deck is produced by one Node script (`build-deck.js`, using [pptxgenjs](https://gitbrent.github.io/PptxGenJS/)) and finished by the Python helpers in `scripts/`. The script is saved next to the output so the deck can be regenerated after any change.

Canvas: `LAYOUT_WIDE` = **13.333 × 7.5 in**, 16:9. All positions are inches, all type sizes are points.

## File Structure

Single deck:

```
my-deck/
  build-deck.js        # the generator (this template, filled in)
  theme.json           # written by build-deck.js; read by scripts/apply-theme.py
  bg-dark.png          # generated backgrounds (scripts/make-background.py), if any
  assets/              # user images, if any
  my-deck.pptx         # output
  package.json         # from `npm install pptxgenjs`
```

Style previews during Phase 2 live in `.powerpoint-slides/previews/` and are deleted at delivery.

## Build Sequence

```bash
npm install pptxgenjs                                   # once per folder (skip if require() already works)
node build-deck.js                                      # -> my-deck.pptx + theme.json
python scripts/apply-theme.py my-deck.pptx theme.json   # real theme colors + fonts
python scripts/add-animations.py my-deck.pptx           # transitions + staggered entrance (see animation-patterns.md)
python scripts/check-pptx.py my-deck.pptx               # 0 errors required; read the outline
python scripts/render-pptx.py my-deck.pptx --grid       # look at every slide
```

`scripts/` paths are relative to this skill's directory.

## Reference `build-deck.js`

Copy this, then change the THEME, the layouts, and the `SLIDES` content. Keep the helper functions; they encode the gotchas.

```javascript
// build-deck.js — generated by the powerpoint-slides skill
// Regenerate with: node build-deck.js && python <skill>/scripts/apply-theme.py my-deck.pptx theme.json
const fs = require('fs');
const pptxgen = require('pptxgenjs');

/* ===========================================
   THEME — the single source of truth for color + type.
   lt1 = default slide surface, dk1 = ink on it (even for dark decks).
   lt2 = alternate surface, dk2 = secondary ink. accent1 = THE accent.
   =========================================== */
const THEME = {
  name: 'Signal',
  headFontFace: 'Source Serif 4',   // display; check with scripts/list-fonts.py
  bodyFontFace: 'DM Sans',          // body
  // eaFontFace: 'Noto Sans KR',    // CJK, if needed
  colors: {
    dk1: '1A2030', lt1: 'F0ECE3',   // ink / paper
    dk2: 'E2DCD0', lt2: '1C2644',   // ink-on-navy / navy
    accent1: 'C8A870',              // antique gold — the only accent
    accent2: '8A96A8', accent3: '4E5A6E', accent4: 'CAC4B4', accent5: '2E3D5C', accent6: '232F55',
    hlink: 'C8A870', folHlink: '8A96A8',
  },
};
const MONO = 'IBM Plex Mono';       // optional label/chrome face
fs.writeFileSync('theme.json', JSON.stringify(THEME, null, 2));

/* ===========================================
   PRESENTATION
   =========================================== */
const pres = new pptxgen();
pres.layout = 'LAYOUT_WIDE';                       // 13.333 x 7.5 in — set BEFORE adding slides
pres.theme = { headFontFace: THEME.headFontFace, bodyFontFace: THEME.bodyFontFace };
pres.title = 'Deck Title';
pres.author = 'Author';
const C = pres.SchemeColor;                        // C.text1, C.background1, C.accent1 ...
const H = THEME.colors;                            // hex, for options that reject scheme colors

// Canvas constants (inches)
const W = 13.333, HGT = 7.5;
const M = 0.8;                                     // outer margin
const CW = W - 2 * M;                              // content width

/* ===========================================
   LAYOUTS — one per slide frame. Text regions are placeholders so the
   deck is editable and restylable from View > Slide Master.
   =========================================== */
pres.defineSlideMaster({
  title: 'TITLE',
  background: { color: H.lt2 },                    // or { path: 'bg-dark.png' } from make-background.py
  objects: [
    { rect: { x: M, y: 2.35, w: 0.5, h: 0.03, fill: { color: H.accent1 } } },   // signature short rule
    { placeholder: { options: { name: 'title', type: 'title', x: M, y: 2.5, w: CW, h: 2.0,
        fontSize: 60, bold: true, color: H.dk2, align: 'left', valign: 'top', margin: 0 }, text: '' } },
    { placeholder: { options: { name: 'body', type: 'body', x: M, y: 4.7, w: CW, h: 1.0,
        fontSize: 22, color: H.accent2, align: 'left', valign: 'top', margin: 0 }, text: '' } },
  ],
});

pres.defineSlideMaster({
  title: 'SECTION',
  background: { color: H.lt2 },
  objects: [
    { placeholder: { options: { name: 'title', type: 'title', x: M, y: 2.9, w: CW, h: 1.6,
        fontSize: 54, bold: true, color: H.dk2, align: 'left', margin: 0 }, text: '' } },
  ],
});

pres.defineSlideMaster({
  title: 'CONTENT',
  background: { color: H.lt1 },
  objects: [
    { placeholder: { options: { name: 'title', type: 'title', x: M, y: 0.6, w: CW, h: 0.9,
        fontSize: 36, bold: true, color: H.dk1, align: 'left', valign: 'top', margin: 0 }, text: '' } },
    { placeholder: { options: { name: 'body', type: 'body', x: M, y: 1.8, w: CW, h: 4.9,
        fontSize: 18, color: H.dk1, align: 'left', valign: 'top', margin: 0 }, text: '' } },
    { line: { x: M, y: 6.95, w: CW, h: 0, line: { color: H.accent4, width: 0.75 } } },     // hairline foot rule
  ],
  slideNumber: { x: W - M - 0.6, y: 7.02, w: 0.6, h: 0.3, fontSize: 10, color: H.accent2, align: 'right' },
});

// Same frame without the body placeholder: for slides composed of cards, stats, charts, images.
pres.defineSlideMaster({
  title: 'CONTENT_TITLE_ONLY',
  background: { color: H.lt1 },
  objects: [
    { placeholder: { options: { name: 'title', type: 'title', x: M, y: 0.6, w: CW, h: 0.9,
        fontSize: 36, bold: true, color: H.dk1, align: 'left', valign: 'top', margin: 0 }, text: '' } },
    { line: { x: M, y: 6.95, w: CW, h: 0, line: { color: H.accent4, width: 0.75 } } },
  ],
  slideNumber: { x: W - M - 0.6, y: 7.02, w: 0.6, h: 0.3, fontSize: 10, color: H.accent2, align: 'right' },
});

pres.defineSlideMaster({
  title: 'CLOSING',
  background: { color: H.lt2 },
  objects: [
    { placeholder: { options: { name: 'title', type: 'title', x: M, y: 2.6, w: CW, h: 1.4,
        fontSize: 48, bold: true, color: H.dk2, align: 'left', margin: 0 }, text: '' } },
    { placeholder: { options: { name: 'body', type: 'body', x: M, y: 4.2, w: CW, h: 1.2,
        fontSize: 20, color: H.accent2, align: 'left', margin: 0 }, text: '' } },
  ],
});

/* ===========================================
   COMPONENTS — the design system's vocabulary, as functions.
   Every function builds fresh option objects (pptxgenjs mutates them).
   =========================================== */
function kicker(slide, text, x, y, w = 6, dark = false) {
  slide.addText(text.toUpperCase(), { x, y, w, h: 0.3, fontFace: MONO, fontSize: 11, charSpacing: 3,
    color: H.accent1, margin: 0, isTextBox: true, objectName: 'kicker' });
}

function rule(slide, x, y, w, color = H.accent4) {
  slide.addShape(pres.ShapeType.line, { x, y, w, h: 0, line: { color, width: 0.75 }, objectName: 'rule' });
}

function bullets(slide, items, box, opts = {}) {
  // items: ['text', ...] or [{ text, sub: ['...'] }]
  // box: { placeholder: 'body' } to fill the layout's body placeholder, or { x, y, w, h } for a free text box
  const runs = [];
  items.forEach((it, i) => {
    const text = typeof it === 'string' ? it : it.text;
    const last = i === items.length - 1 && !(typeof it === 'object' && it.sub);
    runs.push({ text, options: { bullet: { code: '2014', indent: 18 }, breakLine: !last, paraSpaceAfter: 8 } });
    if (typeof it === 'object' && it.sub) {
      it.sub.forEach((s, j) => runs.push({ text: s, options: { bullet: { code: '2014', indent: 18 }, indentLevel: 1,
        fontSize: (opts.fontSize || 18) - 2, breakLine: !(i === items.length - 1 && j === it.sub.length - 1), paraSpaceAfter: 4 } }));
    }
  });
  const common = { fontSize: opts.fontSize || 18, color: opts.color || H.dk1, valign: 'top', margin: 0 };
  if (box.placeholder) slide.addText(runs, { placeholder: box.placeholder, ...common });
  else slide.addText(runs, { ...box, ...common, isTextBox: true, objectName: opts.name || 'bullets' });
}

function card(slide, { x, y, w, h, title, body, dark = false }) {
  slide.addShape(pres.ShapeType.rect, { x, y, w, h, fill: { color: dark ? H.lt2 : 'FFFFFF' },
    line: { color: H.accent4, width: 0.75 }, objectName: `card:${title}` });
  slide.addText(title, { x: x + 0.3, y: y + 0.25, w: w - 0.6, h: 0.5, fontSize: 18, bold: true,
    color: dark ? H.dk2 : H.dk1, margin: 0, isTextBox: true, objectName: `card-title:${title}` });
  slide.addText(body, { x: x + 0.3, y: y + 0.85, w: w - 0.6, h: h - 1.1, fontSize: 14,
    color: dark ? H.accent2 : H.accent3, valign: 'top', margin: 0, isTextBox: true, objectName: `card-body:${title}` });
}

function stat(slide, { x, y, w, value, label }) {
  rule(slide, x, y, w, H.accent4);
  slide.addText(value, { x, y: y + 0.15, w, h: 1.1, fontSize: 54, bold: true, color: H.accent1,
    charSpacing: -1, margin: 0, isTextBox: true, objectName: `stat:${label}` });
  slide.addText(label, { x, y: y + 1.3, w, h: 0.5, fontSize: 14, color: H.accent3, margin: 0, isTextBox: true,
    objectName: `stat-label:${label}` });
}

function picture(slide, path, box, opts = {}) {
  // sizing 'contain' keeps the whole image; 'cover' fills the box and crops
  slide.addImage({ path, ...box, sizing: { type: opts.fit || 'contain', w: box.w, h: box.h },
    objectName: opts.name || 'image' });
}

function chart(slide, type, data, box, opts = {}) {
  slide.addChart(type, data, {
    ...box,
    chartColors: opts.colors || [H.accent1, H.accent2, H.accent3, H.accent5],
    showLegend: data.length > 1, legendPos: 'b', legendFontFace: '+mn-lt', legendFontSize: 11, legendColor: H.accent3,
    showTitle: false,
    showValue: opts.showValue ?? true, dataLabelFontFace: '+mn-lt', dataLabelFontSize: 11, dataLabelColor: H.dk1,
    dataLabelPosition: opts.labelPos || 'outEnd',   // stacked charts: 'ctr' | 'inEnd' | 'inBase' ONLY
    catAxisLabelFontFace: '+mn-lt', catAxisLabelFontSize: 11, catAxisLabelColor: H.accent3,
    valAxisLabelFontFace: '+mn-lt', valAxisLabelFontSize: 11, valAxisLabelColor: H.accent3,
    valGridLine: { color: H.accent4, size: 0.5 }, catGridLine: { style: 'none' },
    valAxisLineShow: false, catAxisLineShow: false,
    objectName: opts.name || 'chart',
  });
}

function table(slide, rows, box, opts = {}) {
  // rows: [[header...], [cells...]]; strings or { text, options }
  const header = rows[0].map(t => ({ text: String(t), options: { bold: true, color: H.dk2, fill: { color: H.lt2 } } }));
  const body = rows.slice(1).map((r, i) => r.map(t => ({ text: String(t),
    options: { color: H.dk1, fill: { color: i % 2 ? H.lt1 : 'FFFFFF' } } })));
  slide.addTable([header, ...body], { ...box, colW: opts.colW, fontSize: opts.fontSize || 13, fontFace: THEME.bodyFontFace,
    border: { type: 'solid', color: H.accent4, pt: 0.5 }, margin: 0.08, valign: 'middle', autoPage: false,
    objectName: opts.name || 'table' });
}

/* ===========================================
   CONTENT — the deck as data. One message per slide.
   =========================================== */
const SLIDES = [
  { layout: 'TITLE', section: 'Opening', title: 'Deck Title', subtitle: 'Subtitle · Author · Date',
    notes: 'Open with the one-sentence thesis.' },
  { layout: 'CONTENT', section: 'Context', title: 'Three things that changed', kicker: 'Context',
    bullets: ['First point, one line.', 'Second point.', { text: 'Third point', sub: ['supporting detail'] }],
    notes: 'Walk the three points top to bottom.' },
  { layout: 'CONTENT_TITLE_ONLY', section: 'Evidence', title: 'Revenue doubled in four quarters', kicker: 'Evidence',
    chart: { type: 'bar', data: [{ name: 'Revenue', labels: ['Q1', 'Q2', 'Q3', 'Q4'], values: [4, 7, 9, 12] }] },
    notes: 'Point at Q3 — that is where the new pricing landed.' },
  { layout: 'CONTENT_TITLE_ONLY', section: 'Evidence', title: 'What the numbers mean', kicker: 'Evidence',
    stats: [{ value: '2.4×', label: 'faster onboarding' }, { value: '38%', label: 'lower churn' }, { value: '11', label: 'new markets' }],
    notes: 'Three stats, left to right.' },
  { layout: 'CLOSING', section: 'Close', title: 'Thank you', subtitle: 'name@example.com', notes: 'Ask for the decision.' },
];

/* ===========================================
   RENDER LOOP
   =========================================== */
let currentSection = null;
for (const s of SLIDES) {
  if (s.section !== currentSection) { pres.addSection({ title: s.section }); currentSection = s.section; }
  const slide = pres.addSlide({ masterName: s.layout, sectionTitle: s.section });

  if (s.title) slide.addText(s.title, { placeholder: 'title' });
  if (s.subtitle) slide.addText(s.subtitle, { placeholder: 'body' });
  if (s.kicker) kicker(slide, s.kicker, M, 0.3);

  const body = { x: M, y: 1.8, w: CW, h: 4.9 };
  if (s.bullets) bullets(slide, s.bullets, { placeholder: 'body' });   // CONTENT layout's body region
  if (s.chart) chart(slide, pres.ChartType[s.chart.type], s.chart.data, { ...body, h: 4.7 });
  if (s.stats) {
    const gap = 0.5, w = (CW - gap * (s.stats.length - 1)) / s.stats.length;
    s.stats.forEach((st, i) => stat(slide, { x: M + i * (w + gap), y: 2.4, w, ...st }));
  }
  if (s.image) picture(slide, s.image, { x: M + CW * 0.62, y: 1.8, w: CW * 0.38, h: 4.7 });

  slide.addNotes(s.notes || s.title || '');
}

pres.writeFile({ fileName: 'my-deck.pptx' }).then(f => console.log('wrote', f));
```

Every placeholder a layout defines must be filled on every slide that uses the layout; an empty one shows "Click to add text" in edit view and `check-pptx.py` warns about it. That is why composed slides (cards, stats, charts, images) use `CONTENT_TITLE_ONLY`, which has no body placeholder, and bullet slides fill `CONTENT`'s body placeholder by name.

## Layout Catalog

Define only the layouts the deck uses, but vary frames across the deck. Typical set:

| Layout | Use | Placeholders |
|---|---|---|
| `TITLE` | first slide | title, body (subtitle) |
| `SECTION` | chapter divider, chromeless | title (+ optional kicker shape) |
| `CONTENT` | title + free body region | title, body |
| `CONTENT_TITLE_ONLY` | composed slides: cards, stats, charts, images | title |
| `TWO_COL` | text left, visual right (or reversed) | title, body-left, body-right |
| `QUOTE` | statement / pull quote, chromeless | body (quote), small attribution text |
| `FULL_BLEED` | image background with scrim and overlay text | title |
| `CLOSING` | thank-you / call to action | title, body |

Dark and light variants are separate layouts (`CONTENT_DARK`, `CONTENT_LIGHT`) when the design alternates surfaces.

Footer text, logo, hairlines, and `slideNumber` go on the layout, never on individual slides.

## Composition Patterns

- **Two-column:** text in the left 55–60%, visual in the right 40–45%, 0.4–0.5 in gutter.
- **Icon + text rows:** small shape or PNG icon in a 0.5 in colored circle, bold header, 14 pt description.
- **Card grid:** 2×2 or 3×1 cards with 0.3–0.4 in gaps; same height, same padding.
- **Stat callouts:** 54–72 pt figure in the accent color, 14 pt label below; three across max.
- **Comparison:** two panels separated by a hairline or surface change, never a thick colored divider.
- **Timeline / process:** numbered steps along a hairline with accent dots; 3–6 steps per slide.
- **Full-bleed image:** `slide.background = { path }`, then a dark `rect` with `transparency: 35` as scrim, then the text.
- **Pull quote:** 32–40 pt quote in the display face, attribution 14 pt in the body face.

Vary the frame every two or three slides. Never run the same bullet layout for the whole deck.

## pptxgenjs Gotchas (verified)

- **Set `pres.layout = 'LAYOUT_WIDE'` before adding anything.** The default is 10 × 5.625 in. Coordinates past the edge are written, not clamped.
- **Hex colors: no `#`, exactly 6 digits.** `'#FF0000'` or `'FF000080'` corrupt the file. Alpha is `transparency: 0–100` on fills/images and `opacity: 0–1` on shadows.
- **Option objects are mutated in place** (values converted to EMU on first use). Build a fresh object for every call; never share a `shadow` or options literal.
- **Shadows:** `offset` must be ≥ 0; use `angle: 270` to cast upward.
- **`letterSpacing` does nothing; the option is `charSpacing`** (points).
- **Lists:** `bullet: true` or `bullet: { code: '2014' }` per run, never a literal `•`. `breakLine: true` on every run except the last. Space paragraphs with `paraSpaceAfter`, not `lineSpacing`.
- **`rectRadius` only works with `ShapeType.roundRect`.**
- **No gradient fills.** Render gradients, glows, grids, and grain with `scripts/make-background.py` and use the PNG as `background: { path }`.
- **Every `addText` without a `placeholder` needs `isTextBox: true`** so screen readers and the Selection Pane treat it as text.
- **Text boxes have built-in inset.** Set `margin: 0` whenever text must align with a shape or rule.
- **Placeholders fill by name:** `addText('…', { placeholder: 'title' })`. A misspelt placeholder or `masterName` fails silently (stray box at 0,0 / blank layout). `addImage({ placeholder })` ignores the placeholder's size; pass `w`/`h`.
- **Speaker notes:** `slide.addNotes('…')` once per slide.
- **Charts stay native.** `addChart` for everything PowerPoint can chart. Set `chartColors`, `showValue`, `dataLabelPosition`, axis label fonts `'+mn-lt'` (theme body font), quiet gridlines, `showLegend: false` for a single series. On stacked charts `dataLabelPosition` must be `ctr`, `inEnd`, or `inBase`. A secondary-axis series needs both `valAxes` and `catAxes` (two entries each) or PowerPoint discards the chart.
- **Scheme colors vs hex:** `pres.SchemeColor.*` works for text and shape fills, which then follow theme changes. Options such as `valGridLine.color`, `shadow.color`, `chartColors`, and table borders need hex: read them from `THEME.colors`.
- **One `new pptxgen()` per output file.**
- **`&` in `pres.company` or a layout `title` must be written as `&amp;`.** Slide text is escaped for you.
- **Fonts are names, not files.** Nothing is embedded. Run `scripts/list-fonts.py` and follow the Font Policy in `SKILL.md`.
- **After `writeFile()`, always run `apply-theme.py`** (otherwise scheme colors resolve to Office's stock palette), then `check-pptx.py`.

## Image Pipeline (Skip If No Images)

**Dependency:** `pip install Pillow`

```python
from PIL import Image, ImageDraw

def crop_circle(src, dst):               # logos on rounded aesthetics
    img = Image.open(src).convert('RGBA'); w, h = img.size; s = min(w, h)
    img = img.crop(((w - s) // 2, (h - s) // 2, (w - s) // 2 + s, (h - s) // 2 + s))
    mask = Image.new('L', (s, s), 0); ImageDraw.Draw(mask).ellipse([0, 0, s, s], fill=255)
    img.putalpha(mask); img.save(dst, 'PNG')

def resize_max(src, dst, max_dim=1600):  # keep the .pptx small
    img = Image.open(src); img.thumbnail((max_dim, max_dim), Image.LANCZOS); img.save(dst, quality=85)
```

| Situation | Operation |
|---|---|
| Square logo on rounded aesthetic | `crop_circle()` |
| Image > 1 MB or > 2000 px | `resize_max()` |
| SVG | convert to PNG at 2× display size first |
| Wrong aspect ratio | `sizing: { type: 'cover' }` in `addImage`, or crop with Pillow |

Save processed images with a `_processed` suffix in `assets/`. Never overwrite originals. Never repeat the same image on multiple slides (except a logo on title + closing).

## Code Quality

- Every section of `build-deck.js` carries a `/* === NAME === */` comment explaining what it does and how to change it.
- `objectName` on every composed shape so the user can find it in PowerPoint's Selection Pane.
- Keep `SLIDES` as data at the bottom; keep the design system (THEME, layouts, components) at the top. Content edits should not require touching the design code.
